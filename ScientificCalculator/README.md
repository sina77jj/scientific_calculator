# ماشین حساب مهدسی با پایتون

این پروژه یک ماشین حساب مهندسی است که با زبان برنامه‌نویسی پایتون طراحی شده است.

## امکانات برنامه
- جمع، تفریق، ضرب و تقسیم
- محاسبه توان
- محاسبه جذر
- محاسبه توابع مثلثاتی (Sin، Cos، Tan)
- محاسبه لگاریتم
- محاسبه فاکتوریل
- ذخیره تاریخچه محاسبات
- نمایش و پاک کردن تاریخچه

## کتابخانه‌های استفاده‌شده
- `math` برای عملیات ریاضی
- `json` برای ذخیره و بازیابی تاریخچه محاسبات

## نحوه اجرای برنامه

ابتدا Python را نصب کنید، سپس در ترمینال دستور زیر را اجرا کنید:

```bash
python calculator.py
```

## هدف پروژه
آشنایی با توابع، شرط‌ها، حلقه‌ها، مدیریت خطاها، فایل‌ها و کتابخانه‌های پایتون.

# ماشین حساب ساده با پایتون

این پروژه نسخه ساده‌تر ماشین حساب مهندسی من است که با زبان برنامه‌نویسی پایتون نوشته شده است.

در این برنامه از دستور `match-case` برای انتخاب عملیات ریاضی استفاده شده است.

## امکانات برنامه
- جمع (+)
- تفریق (-)
- ضرب (*)
- تقسیم (/)
- توان (**)

## ساختار برنامه
- استفاده از تابع `calculator()` برای اجرای ماشین حساب
- دریافت دو عدد از کاربر
- دریافت عملگر ریاضی
- استفاده از `match-case` برای تشخیص نوع عملیات
- نمایش نتیجه محاسبه
- نمایش پیام خطا در صورت وارد کردن عملگر نامعتبر

## نحوه اجرای برنامه

برای اجرای برنامه ابتدا Python 3.10 یا نسخه‌های جدیدتر را نصب کنید؛ سپس دستور زیر را در ترمینال اجرا کنید:

```bash
python simple_calculator.py
```

## هدف پروژه
تمرین و یادگیری مفاهیم پایه پایتون، از جمله توابع، ورودی و خروجی، شرط‌ها و دستور `match-case`.
وهمچنین نوشتن ماشین حساب بدون کتاب خانه و کار با سوییچ
